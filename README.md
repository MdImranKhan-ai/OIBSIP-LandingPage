# 🍛 Zaika Biryani - Premium Restaurant Landing Page

## Oasis Infobyte Internship

### Level 1 Task 1 - Landing Page

A modern, responsive and visually appealing restaurant landing page developed using HTML, CSS and JavaScript.

---

## 📌 Project Overview

Zaika Biryani is a premium restaurant landing page designed to showcase authentic dum biryani, menu offerings, food gallery, customer reviews and contact information.

The website is fully responsive and optimized for desktop, tablet and mobile devices.

---

## 🚀 Features

- Modern Premium UI Design
- Fully Responsive Layout
- Hero Section
- About Us Section
- Signature Menu Section
- Food Gallery
- Customer Reviews
- Contact Information
- WhatsApp Order Button
- Smooth Scrolling Navigation
- Scroll Animations

- Mobile Friendly Design
